# TASK_LOGS 使用说明

本目录用于记录“杨的阅读器”的每一次开发任务。

## 强制要求

每次开始执行任务前，必须新建一份日志。

命名格式：

`YYYY-MM-DD-HHMM-简短任务名.md`

示例：

`2026-07-26-2230-byok-model-routing.md`

## 状态枚举

- 审计中
- 计划中
- 开发中
- 验证中
- 已完成
- 部分完成
- 阻塞
- 已取消

## 日志模板

```md
# 任务：任务名称

- 时间：
- 执行者：
- 状态：
- 本地路径：
- GitHub 上传：否

## 1. 用户原始要求

## 2. 任务目标

## 3. 本次范围

## 4. 明确不做

## 5. 审计结果

## 6. 涉及文件

## 7. 实施计划

## 8. 实际修改

## 9. 数据与配置迁移

## 10. 测试

### 自动测试

### 手工验收

## 11. 风险与已知问题

## 12. 未完成项

## 13. 回滚方式

## 14. 最终结论
```

## 敏感信息

日志中不得写入：

- API Key
- Authorization Header
- 用户完整文档正文
- 用户隐私
- 可直接复用的访问令牌
