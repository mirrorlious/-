## 1. 用户反馈

## 2. 任务目标

- 右侧学习面板增加独立“思维导图”标签。
- “全文结构”和“思维导图”复用同一份 `fullMapData.mindmap`，不重复调用模型。
- 全文结构继续使用纵向可折叠树。
- 思维导图使用中心主题、一级分支和后续节点的连线卡片视图，与结构树形成明显视觉差异。
- 思维导图支持双语、英文、中文显示切换。
- 思维导图可进入现有全屏编辑器。
- 尚未生成数据时，可在思维导图标签中直接生成。

## 3. 明确不做

- 不修改全文结构树的数据格式。
- 不新增模型请求类型或重复生成结构数据。
- 不修改选中文字交互、段落菜单、多段选择、Markdown导入导出和批量解析。
- 不合并到 `main`。

## 4. 审计结果

- 当前 `rightPanelTab` 只允许 `outline / analysis / notes`。

4. 增加思维导图内容、语言切换、生成入口和全屏编辑入口。
