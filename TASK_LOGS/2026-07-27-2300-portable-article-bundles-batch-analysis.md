## 1. 用户反馈与需求

1. 沉浸模式隐藏顶部 Header 后，正文工具栏和右侧学习面板仍保留固定的 64–72px 顶部偏移，形成空白横条，并可能遮挡滚动中的正文。
2. 建立完整文章数据包，保存文章正文以及除语音以外的翻译、全文逻辑、结构树、思维导图、段落解析、题目、批注和笔记。
3. 当前文章可下载为 Markdown。
4. Markdown 可重新上传并完整恢复文章及学习结果，避免浏览器缓存被清理后丢失。
5. 阅读库支持批量选择。
6. 支持顺序执行的批量全文解析队列，可暂停、继续、取消，并跳过已有结果。
7. 支持批量导出 Markdown。

## 2. 本次范围

- 动态吸附顶部偏移：普通模式贴 Header，沉浸模式贴视口顶部。
- IndexedDB 新增 `article-bundles` 与 `batch-analysis-jobs`。
- 文章数据包 schema v1。
- 当前文章 Markdown 单篇导出。
- Markdown 单篇或多篇数据包导入与恢复；普通 Markdown 作为新文章导入。
- 阅读库批量选择、全选、批量解析和批量 Markdown 导出。
- 批量模块：全文翻译、全文逻辑、结构树/思维导图、全文练习。
- 队列默认并发 1，逐模块落盘，已有结果跳过。
- 段落翻译、长难句解析和段落练习写入当前文章数据包。

## 3. 明确不做

- 不导出或恢复 API Key、Authorization、音频 URL、音频 Blob 或浏览器临时 UI 状态。
- 不上传用户 Markdown、正文或数据包到第三方存储。
- 不合并到 `main`。
- 不改 OCR 与 PDF 切分算法。
- 不实现 ZIP；批量导出为一个可读、可重新导入的 Markdown 文件。

## 4. 数据结构

`article-bundles` 每篇文章保存：

- 文章 ID、标题、正文、来源和内容哈希；
- 全文翻译；
- 全文逻辑；
- 结构树 / 思维导图共享数据；
- 全文练习；
- 段落翻译、段落解析、段落练习；
- 当前精读结果；
- 批注和全文笔记；
- schema 版本、模型信息和更新时间。

Markdown 文件同时包含：

1. 人类可直接阅读的 Markdown 章节；
2. `yang-reader-data` JSON 数据块，用于无损恢复。

## 5. 批量队列规则

- 选择阅读库文章后再启动。
- 每次只处理一篇文章、一个模块。
- 每完成一个模块立即写入 IndexedDB。
- 已有结果默认跳过，不重复消耗 API。
- 单篇失败不阻塞后续文章。
- 支持暂停、继续、取消及查看失败原因。
- 队列进度写入 `batch-analysis-jobs`。

- 使用 CSS 变量统一 Header、正文工具栏与学习侧栏的 sticky 偏移；沉浸模式偏移为 0，不再出现顶部空白横条。

- Markdown 同时包含人类可读章节和 base64 编码的 `yang-reader-data` 数据块。
- 支持从主菜单或首页导入单篇/多篇 Markdown；普通 Markdown 也可作为新文章进入阅读库。

## 10. 风险与已知问题

- 批量分析会使用用户自己的模型额度；默认串行并优先复用缓存。
- 大批量 Markdown 文件可能较大，但仍是纯文本，可用常规编辑器打开。
- 浏览器关闭页面后，正在运行的 JavaScript 队列不能继续执行；任务进度会保留，可重新选择未完成文章继续处理。
